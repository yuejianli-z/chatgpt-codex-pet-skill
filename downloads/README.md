## 怎么用

按你要的东西选一条路线：

**1. 只要 Skill（自己做宠物）**
解压 `pet-skill-3.3.7.zip`，把里面的 `create-desktop-companion` 文件夹复制到 `%USERPROFILE%\.agents\skills\`（Codex）或 `%USERPROFILE%\.claude\skills\`（Claude Code）。完整步骤见 [Skill 安装](../skills/create-desktop-companion/docs/zh-CN/installation.md)。

**2. 现成宠物：装到 Codex 桌面 App**
解压所选宠物 ZIP，把得到的 `<角色>` 文件夹（含 `pet.json`、`atlas.png`）复制到 `%USERPROFILE%\.codex\pets\`，然后在 Codex 的 Settings → Pets 里点击刷新并选择。每包内都有 `INSTALL-zh-CN.md`，写着同样的步骤。

**3. 网页端（暂未验证）**
官方 ChatGPT 网页的宠物上传说明写的尺寸是 1536×1872，与本包 2288 高的图集不同，我们没有验证网页端能否接受本包。请先按路线 2 在 Codex 桌面 App 中使用；网页端在官方说明与本包规格对齐、并实际验证之前，不要按本包直接上传。

注意：解压不等于已安装；没有自定义宠物入口的客户端不能仅靠素材包启用；桌面悬浮窗只支持 macOS 和 Windows。本包的路径和步骤在本机 Windows 上依据官方文档核对，但**未在所有 Codex 版本上实机测试**。
