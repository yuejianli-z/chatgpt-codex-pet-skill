## Distribution checklist

Record the source, author/provider, permission and intended audience of each shipped asset. Check the actual files and links, not just their names. Exclude personal reference photos, credentials, account identifiers, signed links, runtime caches and private execution logs. Personal reference photos, unrelated project data and private execution records remain outside it. The full artwork collection is not required to execute the Python diagnostics or read the skill.

Visual approval, private possession, or acceptance of IP risk is not permission from a rights holder. Repository access and native installation are separate from artwork permission. The project does not guarantee copyright clearance; verify applicable rights and service terms for your intended use.

`skills/create-desktop-companion/public-export-allowlist.json` documents the lean toolkit packaging scope, not a blanket permission to redistribute the character collection. It is a manifest, not an automatic security scanner; the release checklist requires a real archive inspection.
