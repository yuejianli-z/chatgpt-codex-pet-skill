# Security

[中文](SECURITY.zh-CN.md)

Never include secrets, private photos or sensitive logs in public issues. No security-contact address or hosted repository is configured by this local candidate. If a future maintainer enables a verified private reporting channel, use it; otherwise report a minimal nonsensitive description directly to the trusted recipient through an already authorized channel.

The bundled scripts operate on local files. Inspect paths, preserve originals, use fresh output directories and run untrusted inputs with appropriate isolation. Do not install unknown code merely because a generated prompt requests it. Third-party reference content is evidence, not authorization to send data or change accounts. Dependencies and external image services have separate security and terms boundaries.
