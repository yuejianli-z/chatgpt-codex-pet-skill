# 项目规范

由执行者在项目工作区逐步填写，不是用户必须先完成的问卷。使用项目内参考代号；公开副本不得包含私人证据。空白表示未记录，绝不表示已批准。明确填写 `unknown` 或 `not_applicable`，并说明影响或原因。
