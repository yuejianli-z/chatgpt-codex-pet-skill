# Selected-action generation brief

Template for future generation, not an executed production prompt. Fill from the approved action proposal; remove instructions that do not apply. Never rewrite a historical executed prompt with this template.

- Host state key / verified system meaning:
- Exact interface surface / client/version; trigger and row binding verified with evidence, or unknown:
- Output is representative key pose(s) or a complete ordered row; expected versus actually generated frames:
- One chosen action, stated concretely (no “thinking or typing or scanning” menu):
- Evidence label and source behavior; what is adapted rather than canonical:
- Attention target / addressee and primary readable cue:
- Moving parts / fixed anchors / per-actor ownership:
- Required anatomy and existing equipment; absent features that must not appear:
- Sequence type and source-frame budget from the adapter:

- For sustained thought: specify how every phase, including loop reset, remains thought rather than idle/greeting/request.
- For request: identify the user-facing ask and patient waiting cue; do not show granted approval.
- For events: state preparation, contact/support and recovery; no contradictory task outcome.
- Camera, shared scale/registration, allowed deformation, edges/background and adapter constraints:
- Source and final-frame identity/semantic review plan:
- Conflicting stock clauses removed; remaining brief contains only the chosen action:
- User-approved motion scope / unexecuted or executed date and immutable record:

A generator can realize this performance, not choose what the state ought to mean. If the chosen action cannot fit the anatomy or frame budget, return to action planning rather than inventing parts or a different gesture.

- Requested final format and reference: if animated, this source job contributes real within-state motion; a key-pose preview does not fulfill the final animation request.

- Combined bilingual showcase: real track motion, single-character gaze and requested body views. Action words and separate meaning labels use both languages; detailed evidence belongs in companion notes. Separate layout from identity sources and provide a representative-frame overview and private reproduction package.
