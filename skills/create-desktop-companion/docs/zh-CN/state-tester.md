# 离线状态测试器

用现代桌面浏览器打开 `tools/state-tester/standalone.html`，选择本地 PNG 或 WebP 图集即可。无需服务器、安装、账号、上传或网络服务。默认中文，可点 English 切换。公开包不包含角色作品。

接受的是已记录的八列 Pets 图集格式：单格192×208，v1为1536×1872，v2为1536×2288，文件不超过20 MiB。九种动作帧数依次为6、8、8、4、5、8、6、6、6，共57帧；v2另有16个静态视线姿态，共73格，从向上开始顺时针每22.5°一格。这不是25种动画。其他宿主格式需要另做适配。

1. 选择准备检查的同一份已批准原始图集，核对显示的文件名和版本。
2. 点动作或v2视线姿态；可暂停、逐帧、拖动帧滑块、调整大小和背景。FPS与倍速是模拟设置。
3. 一键遍历所有状态，再测试末帧↔首帧接缝、中途切换或手动硬切。工具不插帧，也不实现宿主混合。
4. 为看过的状态填写人工结论和备注。关闭页面或换图集前导出QA JSON，记录只保存在当前标签页。含私人文件名、备注的报告未经授权不要公开。

覆盖记录只表示本工具显示过相应源格，不证明人工看过、质量通过、权利已获许可、已安装、真实宿主时序、随机调度或运行验收。本工具不能控制已安装的Dot宠物；真实客户端观察与连续长时观看仍要单独记录。

测试命令见 `tools/state-tester/README.md`。Python诊断及测试与浏览器工具分别验证。单文件版由已审查的HTML与JavaScript生成，不要单独编辑。

## 本版验证边界

控制器与独立审查测试使用模拟DOM/画布，核验状态逻辑，不核验真实浏览器渲染或图片解码。所附浏览器冒烟测试尚未在本环境执行；下载、布局和视觉播放仍待验证。

解释任务文案、安排常驻形态或宣称实际占比前，先读[运行状态证据](runtime-state-evidence.md)。

当前验证环境中 Chromium 启动受阻，浏览器渲染未获验证；附带冒烟脚本也不测试下载交互。见[验证记录](../validation.md)。
