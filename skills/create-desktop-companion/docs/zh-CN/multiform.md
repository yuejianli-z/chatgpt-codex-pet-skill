# 多形态设计与能力预检

## R06 — 一个身份、一张图集、受支持事件映射

区分同一身份多形态、多只独立伴侣、离线三形态演示、动作行内设计变形及宿主自动变形。完成其中一项不证明其他项。用户要求一只多形态伴侣时，三只pet或三块并排展示板不能替代。

记录每形态批准来源、不变量、主体/配件归属、逐状态形态映射、主形起止锚点、固定帧预算、过渡源帧索引、循环与中断证据。一个适配器示例是一张图集含九动作行（57帧）和16方向；不能把第二套形态藏入未用透明格，也不能假装description字段能执行逻辑。

在支持范围内，常态及方向保持主形；将短暂附加形态映射到某个已有事件，行首行尾回主形。保留状态含义：跳跃仍起跳落地，失败仍有反应。若五帧容不下变形和核心动作，保留未通过或修订范围，不能虚构帧数或删去核心动作。独立附加形态待机演示不证明宿主自动变形。

主形常见的愿望在测量前只是意图。图集占格数与离线视频比例都不是宿主概率。没有实际契约及运行证据，不承诺80/10/10、冷却、驻留时长、后台调度或任意打断无缝。

### 能力证据矩阵

| 能力 | 必需证据 | 未知时 |
|---|---|---|
| 固定状态/帧预算 | 当前宿主schema | 不宣称可导入 |
| 持续形态变量 | 实际API与运行测试 | 仅设计单行内变化并回主形 |
| 随机概率/冷却/计时 | 可设置字段与实际行为 | 占比保持意图，不虚构调度器 |
| 自定义事件/分支 | 宿主事件契约 | 用已有状态语义或独立演示 |
| 混合/中断 | 实际进入/保持/退出切换测试 | 离线硬切标为风险，宿主无缝未证实 |

## R14 — 承诺产物前核验工具

本包是可移植助手方法与诊断代码，不是模型、生成服务、应用安装器或完整板渲染器。分别核验工具及数据传输授权：

- 仅文本：交付规格或计划，不能声称已生成或看过图。
- 读图：检查输入身份；私人照片反向搜索另需授权。
- 图像生成/编辑：核实用户选用的提供方实际可用及费用/数据边界。包内不附提供方或凭据。
- Python 3.10+与Pillow：支持诊断和原创几何测试fixture。移动矩形测试像素，不证明生物动作、身份或舒适。
- ffmpeg：可选编码/探测依赖。另用项目自有或合法可用渲染器；包内不含完整角色板渲染器。
- 原生尺寸真实播放：人工30/60秒观看必需，解码不能替代。
- 宿主导入/上传：独立可选适配层。仅在工具可用时按当前官方说明使用；安装本skill不授予平台API或创建pet。不再分发未知许可的平台实现，不编造下载链接。

使用仓库说明中的预检/测试命令确认机器准备情况。逐项记录可用、不可用或未测；fixture通过不证明角色制作成功或宿主支持。

解释任务文案、安排常驻形态或宣称实际占比前，先读[运行状态证据](runtime-state-evidence.md)。
