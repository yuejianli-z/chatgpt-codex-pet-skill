# 兼容性与能力范围

[English](../en/compatibility.md)

需要区分三层：读取 Skill、制作资产、运行桌宠。支持其中一层，不证明另外两层也可用。

## 已包含

- Markdown 工作方法、双语模板与 Python 3.10+/Pillow 诊断。
- 固定 v2 图集组装器、结构校验器与源动画预览导出器，见[独立制作](openai-production.md)。需要已准备并对齐的源帧，不负责生成画稿或安装桌宠。
- 支持固定 Pets 风格 v1/v2 图集的离线浏览器查看器。
- Node 控制器测试、可选 Playwright 浏览器冒烟测试与原创合成素材。
- 通用 SVG 线稿教学样例，不是任意角色渲染器。

## 需要外部工具

图像生成与编辑、完整角色展示板或视频合成、原生宿主导入与选择、宿主生命周期事件。本项目没有实现通用导出器、事件桥、跨 Agent 播放器、音频引擎或新增原生适配器。

## 查看器契约

PNG/WebP，最大 20 MiB，8 列，每格 192×208。v1 为 1536×1872，v2 为 1536×2288。九条动作轨依次为 6/8/8/4/5/8/6/6/6 帧，共 57 帧；v2 另有从上方起顺时针排列的 16 个注视采样，共 73 个有效格、15 个空格。查看器检查布局与大小，不代替完整的生产内容验收。

帧率、慢放、循环接缝和硬切均为模拟设置，不改变原生时序，也不证明真实触发、随机性、停留、混合、指针追踪或安装后尺寸。宿主验证必须记录具体产品、版本与界面。

## 接入原则

优先使用核实过的原生导入入口。宿主没有此入口时，Mod 或外置播放器是独立工程，不会因安装 Skill 自动出现。保留目标中立的源帧、时长、锚点与动作含义，仅按核实过的契约导出。

[平台说明](platform-foundation.md)与[运行证据](runtime-state-evidence.md)区分接口记录和运行实测。

## 声音

2026-10-23 记录的自定义 Pets 上传/创建/更新接口接收图集与元数据，没有音频上传或动作音效映射字段，因此本工具包不通过该路径提供已安装桌宠声音。这不是对所有未来接口的判断。MP4 音轨只是演示媒体；GIF 不支持音频。
