## 可选的独立私有展示素材集

具体项目的角色展示板、动画预览和源图集应另存于独立私有素材集，不混入代码仓库。私有仓库仍会将数据传给托管服务及获准协作者。上传前逐项确认文件、目的地与访问范围。默认排除个人参考照片、执行提示词、凭据及账户截图。

每份获准素材应记录文件名、SHA-256、项目和版本、作者或生成来源、目标受众、第三方角色及来源权利、是否获得再分发许可。权利不明时标注“仅供私下审阅；再分发尚未获许可”。视觉认可、私人持有及代码的 MIT 许可均不代表第三方权利已经解决。本文不会创建或上传私有素材集。

见[素材政策](../../ASSET-POLICY.zh-CN.md)与[来源说明](../../SOURCE-CREDITS.zh-CN.md)。

## README 的 GIF 展示

GitHub 支持在 README 中展示动画 GIF：[官方工程案例](https://github.blog/engineering/infrastructure/4-ways-we-use-github-actions-to-build-github/)记录了把生成 GIF 放入团队 README。获准且可访问的 GIF 可以直接嵌入，不必只展示静态截图。使用真实素材路径与中英替代文字，获准上传后再检查实际 README 渲染；不编造素材或仓库地址。

不能保证每位观看者都自动播放：[GitHub 动态设置](https://docs.github.com/en/enterprise-cloud%40latest/account-and-profile/how-tos/account-settings/managing-accessibility-settings#managing-motion)默认跟随系统减少动态偏好，也可启用/禁用动图自动播放。保留可读首帧及可选静态总览，不替观看者更改偏好。准备嵌入不授权上传私人角色作品或发布仓库，本包不附角色 GIF。
