# 发布检查清单

[English](../en/release-checklist.md)

- [ ] 冻结精确候选树与文件hash，保留旧归档。
- [ ] 从全新解压ZIP运行全部测试与README命令，不只测工作目录。
- [ ] 检查相对链接和英中规则/字段对等；必须/可以/未知/未测含义一致。
- [ ] 实际包逐文件白名单，不含缓存、私人输出、个人照片、未经分发许可的角色作品、凭据、私有ID/路径、执行日志。
- [ ] 核对原创流程图/几何署名及依赖/许可证边界。
- [ ] 诊断不证明身份、舒适或宿主运行；30/60片未观看如实写。
- [ ] 明确不附图像提供方、完整角色合成器、应用安装器或平台API。
- [ ] GitHub CI未真实运行前仅称配置，本地测试是另一证据。
- [ ] 公开发布/创建远端仓库须单独授权，准备候选ZIP不等于已发布。

## 局部修复证据

- [ ] 涉及认可素材局部修复时，冻结受保护像素、锁定身份特征后再修改。
- [ ] 正向反馈限于所见结果，保留离散视线及运行验证缺口。
- [ ] 把获准可见填充的制作/回读结果与仍未验证的无填充迁移及原生实播分开。

- [ ] 最终合成及编码文件通过适用门禁，不能只引用前版动作行。
- [ ] 正确区分存储字节与解码 RGBA 一致性；库存回读不升级为选中或运行证明。
