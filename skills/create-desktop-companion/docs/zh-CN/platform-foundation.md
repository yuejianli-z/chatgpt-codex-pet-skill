# 平台基石与验收证据

先核实目标平台。看起来有三维体积，不代表支持3D网格、骨骼、物理或SVG。以真正接受的素材契约为准；精灵渲染器可能只接受位图图集。不同产品与客户端不能混为一谈。

## 证据分类

| 类别 | 所需证据 | 不能证明什么 |
|---|---|---|
| 宿主硬约束 | 当前权威schema或确切素材/版本的直接验证结果 | 动作自然、身份一致 |
| 强制制作门禁 | 当前适用工作流要求与未改动的检查结果 | 服务端拒绝、法律状态、内容禁忌 |
| 启发式诊断 | 测量、源图比较、问题区域审查 | 确定存在缺陷、可自动豁免 |
| 预览行为 | 导出时间线、解码帧与设置 | 客户端调度、帧率或中断融合 |
| 实际运行观察 | 实际目标客户端、确切素材/版本与观察记录 | 其他客户端/版本或未观察状态 |
| 内容限制 | 对应服务的明确结果 | 版权归属或该画风被普遍禁止 |

每项能力记录来源、版本/日期、适用范围，以及支持/不支持/未知。不支持须有明确否定证据，未知表示尚未证实。不能从演示或上传成功推导随机待机、驻留概率、自定义状态、可设FPS、事件冷却、实时3D、注视插值或状态融合。

## 确定制作预算之前

- 目标产品/客户端/版本、实际显示大小；文件格式、尺寸、透明要求、大小上限、图集布局。
- 必需状态键、帧数/顺序、方向目录与坐标约定；技术状态名和艺术表达分开。
- 哪些是权威要求、哪些仅为注明日期的快照、哪些待重新核实。示例数量不能泛化。
- 帧时长、循环/单次、驻留、进入/退出、中断、注视优先级、错误回退：逐项写证据或未知。
- 支持的导入、更新、启用、回退路径；当前选中身份与保留基准。不能仅为探索格式就修改实际宠物。
- 工具能力和支持的验证路径；集成被阻时可继续有价值的概念/预览，但须标清范围。

## 四种独立交付声明

这是证据维度，不是自动晋级阶梯。上传成功不能抵消失败门禁，安装也不等于实际验收。

1. **可展示：**确切预览能打开/解码，交付范围明确；静态或局部样例仍标清。
2. **格式与制作就绪：**最终素材符合当前目标契约、所有适用强制门禁通过，且有受支持的结构预检结果。创建/内容审核在单独验证前仍待通过；该级别绝不保证安装成功。没有该路径时写“候选；安装资格未核实”。
3. **已安装：**获授权操作对确切素材返回肯定结果；声称当前启用还需选中/启用回读。仅准备文件或提交请求不足以证明。
4. **实际验收：**目标客户端真实观察覆盖已声明测试范围，并列出未解决问题、未测状态。离线播放不能满足该维度。

素材字节、门禁、适配器或客户端版本变化后重验受影响声明。缺证据写未知，不升级状态。`scripts/check_platform_claims.py`仅检查记录自洽，不能认证证据真伪或运行宿主。

## 状态、时序、中断检查单

每个必需状态记录：触发方式/证据、实际素材身份、观察到的时长和帧时序、循环/单次语义、接触/姿态/速度接缝、原生尺寸可读性、覆盖缺口。持续状态按[质量](quality.md)做30/60秒观看；人工触发测试不能推导自然驻留频率。

按实际支持范围检查进入→保持、保持→退出、退出→待机、待机↔工作、状态↔注视，在前/中/后相位测试。另查重复触发、短任务、单次动作中途被打断、失败/恢复。不可用或无法触发的路径如实记录，不能凭空造出。多形态须专测变身被打断。离线硬切模拟与客户端实测分开。全过程保留注册位置、轮廓和面部身份。

## 修改批准形象前先分类诊断

保留原失败报告与素材hash。分辨结构、抠图、视觉缺陷、启发式疑似、服务限制或实际运行问题。深浅背景比较受影响区域抠图前后。用例复现误报仅说明诊断局限，不能证明角色全部告警都是误报。

合适的纯几何回归集包括：与外界相连的U形留白、有意闭合环、意外内部横缝、与背景相连的裂缝、狭窄/抗锯齿通道、正常分离部件与断裂部件。开放留白不能错称封闭洞；但外连透明不代表真实裂缝可以放行，闭合环也不必然是破损。真实横缝、轮廓破损、缺失身体仍须检出或进入审查。测试4/8连通和alpha阈值敏感性。

不能修改强制bundled检查器、删失败字段、降低阈值，或为过门禁填满有意留白。补充诊断不覆盖门禁。只有证明抠图出错，才从原素材恢复有依据的像素，随后重跑全部门禁与身份检查。如果门禁拒绝已批准的有意留白、又无受支持豁免，就保留造型、说明兼容性阻塞并仅交付预览。可以提出维护/申诉路径，但不能称其已实现，也不因此获得向第三方发信的授权。

解释任务文案、安排常驻形态或宣称实际占比前，先读[运行状态证据](runtime-state-evidence.md)。
