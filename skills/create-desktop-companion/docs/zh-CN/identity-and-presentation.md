# 保持身份的角色展示

[English](../en/identity-and-presentation.md) · [简体中文](../zh-CN/identity-and-presentation.md)

## 1. 排版与角色艺术分别认可

认可排版，不等于认可其中已变形的角色。概念大板只提供分区、层级、字体与间距。恢复最新适用的获准角色源稿，不把整板重新生成成一张新插画。版式配置与角色美术分文件管理。

组合展示包括真实动作循环、单体逐向注意力展示和要求的静态身体视角。当前编辑画册示例为左大追视、左下四视角单排、右侧九动作。这是可配置示例，不是永久宽高比或宿主要求。实际查看最新参考像素，分开记录布局、角色、姿势、材质与最终验收。

对齐 viewport、间距、外边线和文字基线，不强迫不同姿态轮廓相同，不逐帧缩放填格、拉伸身体或把腾空帧压回地面。图内用中英短标签：上层具体动作，下层状态/用途。证据和限制放配套说明，不堆底部小字。

## 2. 建立身份与真实来源链

记录本次适用的批准参考及版本/hash。固定体型、头身关系、肢体数量和连接、腿长、花纹、尾巴数量/根部/相对长度/形态，以及非对称配件。尾巴可以合理运动，不能变成另一条尾、根部漂移或多出肢体。

锁定身份不是冻结像素。合理透视、关节运动、配件随头运动及自然遮挡均可发生；检查连接、数量、相对尺寸和重新出现时的一致性。未见背面花纹是明确标注的设计补全，不是照片或原作已证明。被否定的概念图不得覆盖批准基准。

旧安装图、新生成源帧、概念排版、最终组合导出分别立证据链。记录真实输入版本/hash、实际受检文件hash、QA范围和已核实来源关系。未知保持未知：旧图缺陷不能直接证明新图有缺陷，源稿曾通过也不能替概念图或编码文件背书。日期、名字和相似外观不是来源证明。

## 3. 追视是注意方向，不是全身转台

使用适配器已核实顺序。有日期边界的 Pets v2 示例中，000向上、090屏幕右、180向下、270屏幕左，顺时针每22.5度共16个样本。不是16任务状态，不是中性加15向，也不是16次全身旋转。

保持可比较的站位和尺度，通常由眼睛及有限头颈运动表达，按真实结构适配。耳、发、帽子和眼镜可随头动，但身份和连接不变。不用躯干拉伸、尾巴换型或换身体表示方向。无脸/机械角色只能用已有且明确说明的方向线索，不加眼睛、脖子或独立部件。方向不清楚就说明，不能强称完美追视。

在目标尺寸和解剖局部放大下查看全部16张，核对主方向、相邻连续性、对向区别、尾根/尾型/四肢及非对称细节。16格有图或不同不证明方向和身份正确。扫视预览只证明顺序播放，不证明原生鼠标跟随或插值。遵循目标的必需制作/返修管线，本方法不豁免任何强制门禁。

## 4. 每个角色独立设计，不套同一组手势

来源使用个体/物种观察、同版本IP已核实表演，或符合结构的常见动作；明确区分观察、改编与兜底。自然动作不会天然等于软件状态。保留获准有效动作，未看过的新版本标未审，不从旧安装图倒退重设。

每轨确定一个动作、注意目标、来源、简洁理由、最近易混淆项及可见区别。选一至两个强化特征与可读性的小巧思，不随意添道具。四业务含义、九动画轨和十六注意方向分开。处理中整圈仍在处理，请求始终面向用户；Ready表示已有成果可查看，不是无尽未完成工作。完成手势没有统一禁令，按实际整轮含义验收。待机、移动、招呼、跳跃不强塞进四业务标签。

保留明确获准的变身。实际帧必须看见变换过程、目标形态及同一身份连续性，不能只给变身后的静姿。到达新形态后的思考手势不能替代变身本身；运行时触发另行核实或标未知。

## 5. 源帧与最终导出分别检查

逐帧检查身份、结构、含义、方向、时间与裁剪。对照末两帧和首两帧，检查支撑、起落、尺度、纹理、附属物惯性及合理停顿。去标签看完整循环并与相邻易混淆状态比较，首帧可认不代表持续含义成立。

组合、重采样、调色或编码后，重新解码并查看实际最终GIF/视频。生成、解码、视觉审阅和实际看过分别记录。几何检查、hash、编码退出码不能判断像不像、舒适或运行正确。上传重新编码改变文件字节时，可按需比较解码RGBA；等价只证明内容保真。原生触发、鼠标行为和长时观看未经实际观察仍标未验。

## 6. 代表帧封面、迭代与交付

静态总览逐轨选最能说明动作的已审源帧。首帧确实代表动作时可以用，不默认全取首帧。记录版本/hash、索引、理由。各面板可取不同相位，标为代表姿态总览，不冒充同一动画时间点；不能为了封面改动画顺序或节奏。

每次迭代记录观察到的问题、获准范围、实际改动、受检文件、结果和剩余限制。保留旧版、失败样本与实际执行提示词，候选提示不是生成证据。

交付组合动态、代表帧静态总览、私有源素材/复现包及逐角色简洁设计/迭代说明。通用方法包与私人图片、照片、标识分离。制作授权不等于安装、启用、公开再分发或仓库发布授权。方法文档更新本身不能修好或认证角色美术。


## 混用源素材前的跨行尺度注册

新条带通过自己的抽帧/行内检查，不代表能与旧图集按同一名义倍率直接混用。提取时的尺度或锚点可能不同。验收组合图集或展示板前，必须比较获准待机/参考行与每个新行之间的状态切换。

以获准的中立姿态或可比姿态作为身份锚，在相同物理尺度下比较稳定的头部、躯干特征尺寸、身体比例，以及预期脚底/接触或悬浮锚。动作抬爪、张翼、摆尾或跳离地面都可能增大整幅bbox高度，因此bbox不能单独代表角色尺度。没有可比姿态时记录不确定性，用多个稳定特征核对，不能强行等高。

保留原始提取帧与提取尺度/平移。若整组源一致偏大或偏小，对该完整组应用一个有记录的共享尺度和注册变换，按参考接触锚对齐。同组各帧及共用该源注册的动作行保持同一变换。禁止逐帧按自身bbox拟合、把所有姿态变成一样高或抹掉腾空位移。若组内尺度不一致，应修正提取或源美术，不能用逐帧拟合掩盖。

记录源版本/hash、原提取变换、中立参考帧与特征点、带单位的特征尺寸、最终整组尺度/平移、锚点、影响帧和最终注册源hash。复查待机→每个改动行→待机、原生尺寸身份、支撑/腾空运动和循环接缝；组合编码后另看实际输出。数字尺度修正只证明注册处理，不自动判断解剖、像不像或动作语义。
