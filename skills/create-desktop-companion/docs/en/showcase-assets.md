## Optional private showcase collection

Keep project-specific character boards, animation previews and source atlases in a separate private asset collection, outside the code repository. A private repository still transmits data to its provider and authorized collaborators. Review the exact files, destination and access before any upload. Exclude personal reference photographs, execution prompts, credentials and account screenshots by default.

Each approved asset should record its filename, SHA-256, project/version, creator or generation provenance, intended audience, third-party character/source rights, and whether redistribution is authorized. Label uncertain rights “private review only; redistribution not cleared.” Visual approval, private possession and the code's MIT license do not establish third-party rights. No private collection is created or uploaded by these instructions.

See [asset policy](../../ASSET-POLICY.md) and [credits](../../SOURCE-CREDITS.md).

## README GIF display

GitHub supports animated GIF images in README content: its [official engineering example](https://github.blog/engineering/infrastructure/4-ways-we-use-github-actions-to-build-github/) describes placing generated GIFs in a team README. An approved, accessible GIF can therefore be embedded directly rather than offering only a static screenshot. Use the actual asset path and bilingual alt text; verify the rendered README after an authorized upload. Do not invent an asset or repository URL.

Autoplay is not guaranteed for every viewer: GitHub's [motion settings](https://docs.github.com/en/enterprise-cloud%40latest/account-and-profile/how-tos/account-settings/managing-accessibility-settings#managing-motion) follow system reduced-motion preferences by default and let users enable or disable animated-image autoplay. Keep a readable first frame and optional static overview; do not change the viewer's preference. Preparing an embed does not authorize uploading private character art or publishing a repository. No character GIF is bundled here.

## Attributed demonstration media

Character demonstration media belongs to the full repository gallery, not this installable kit. Gallery media is not required by any instruction or diagnostic here.
