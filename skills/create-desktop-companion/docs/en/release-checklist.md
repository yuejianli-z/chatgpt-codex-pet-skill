# Release checklist

[中文](../zh-CN/release-checklist.md)

- [ ] Freeze exact candidate tree and file hashes; retain prior archives.
- [ ] Run all tests and README commands from a clean extracted ZIP, not the working tree alone.
- [ ] Check relative links and English/Chinese rule/field parity. Canonical English and Chinese guide must agree on must/may/unknown/unverified.
- [ ] Check actual archive against an explicit allowlist; exclude caches, generated private outputs, personal photos, unapproved character art, credentials, private IDs/paths and executed logs.
- [ ] Verify workflow/geometry attribution, demo-media notices and dependency/license boundaries.
- [ ] State diagnostics do not certify identity, comfort or host execution. Label any unwatched30/60 clips honestly.
- [ ] State no image provider, full character compositor, application installer or platform API is bundled.
- [ ] Treat CI configuration as unexecuted on GitHub until actually run there; local tests are separate evidence.
- [ ] Public publication/remote repository creation is a separate authorized action. A prepared candidate ZIP is not published.

## Focused repair evidence

- [ ] For localized approved-art repairs, freeze protected pixels and lock identity landmarks before editing.
- [ ] Keep positive user feedback scoped to the viewed result; retain discrete gaze and runtime gaps.
- [ ] Separate the authorized visible-fill production/readback result from unfilled transfer and native playback, which remain unverified.

- [ ] Final composition and encoded file, not only precursor rows, passed applicable gates.
- [ ] Stored-byte versus decoded-RGBA equivalence is recorded accurately; no selection/runtime claim from inventory readback.
