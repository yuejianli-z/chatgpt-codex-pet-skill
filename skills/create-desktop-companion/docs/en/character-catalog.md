## How to use the catalog

Choose the exact reference version, record what was inspected, and derive actions from observed anatomy or same-version performance. A species reference does not establish an individual animal's markings. A fan character is not an official mascot. See [asset policy](../../ASSET-POLICY.md) for distribution boundaries.
