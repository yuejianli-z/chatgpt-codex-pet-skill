The MIT license covers contributor-owned code, method documentation, templates, original workflow diagrams, generic line-art specimens, and synthetic geometric fixtures. It does not grant rights to third-party characters, brands, reference media, personal photographs, or project artwork generated using external services.

## Bundled assets

- Language badges and workflow diagrams: contributor-authored, MIT; see [source credits](SOURCE-CREDITS.md).
- Synthetic fixtures and generic line-art geometry: original teaching/test material, MIT.
Character demonstration media is distributed separately in the full repository gallery, outside this installable kit. See each asset’s own rights notice; no character reuse license is conveyed here.
- Character catalog: textual attribution and design examples only, not a character-art pack or rights clearance.

## Distribution checklist

Record the source, author/provider, permission and intended audience of each shipped asset. Check the actual files and links, not just their names. Exclude personal reference photos, credentials, account identifiers, signed links, runtime caches and private execution logs. Keep project assets outside the reusable toolkit unless their inclusion is explicitly permitted and documented.

Visual approval, private possession, or acceptance of IP risk is not permission from a rights holder. Repository access and native installation are separate from artwork permission. The project does not guarantee copyright clearance; verify applicable rights and service terms for your intended use.

`public-export-allowlist.json` documents intended packaging scope. It is a manifest, not an automatic security scanner; the release checklist requires a real archive inspection.

## Takedown requests

If you are the rights holder of any character, artwork or reference used in this project and believe it infringes your rights, please open an issue at <https://github.com/yuejianli-z/chatgpt-codex-pet-skill/issues> or contact the repository owner directly through their GitHub profile. On a verified request, the affected asset will be removed or replaced promptly.
